# ♟ Chess Openings Lab

Web app d'apprentissage des ouvertures aux échecs : les 10 meilleures ouvertures (Blancs), 10 défenses (Noirs) et 10 systèmes, avec pour chaque position les meilleurs coups selon les parties masters (explorateur Lichess).

## Stack
- React + Vite
- chess.js (logique)
- react-chessboard (échiquier)
- API Lichess masters explorer (données réelles, sans clé)

## Dev
npm install && npm run dev

## Build
npm run build
